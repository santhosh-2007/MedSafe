# MEDSAFE - Data Dictionary

All datasets use synthetic data generated by `scripts/generate_data.py` and cleansed by `scripts/clean_data.py`.

## 1. Patients (`patients.csv`)

| Field Name | Type | Description |
|---|---|---|
| `patient_id` | String | Synthetic Identifier (P001-P100, DEMO-001 to DEMO-008) |
| `age` | Integer | Patient age in years |
| `sex` | String | Male / Female |
| `ward` | String | Hospital ward location |
| `admission_date` | String | ISO Date (YYYY-MM-DD) |
| `consent_status` | String | CONSENTED |

## 2. Medications (`medications.csv`)

| Field Name | Type | Description |
|---|---|---|
| `patient_id` | String | Foreign key to Patients |
| `medication_name` | String | Normalized drug agent name |
| `dose` | String | Dosage (e.g. 500mg, 10mg) |
| `route` | String | Administration route (Oral, IV, Subcut) |
| `start_date` | String | Order start date |
| `end_date` | String | Order end date (empty if active) |
| `status` | String | ACTIVE / ENDED |

## 3. Allergies (`allergies.csv`)

| Field Name | Type | Description |
|---|---|---|
| `patient_id` | String | Foreign key to Patients |
| `allergen` | String | Allergen string (e.g. Penicillin, Aspirin) |
| `reaction` | String | Clinical reaction (e.g. Anaphylaxis, Rash) |
| `severity` | String | MILD / MODERATE / SEVERE |
| `recorded_date` | String | Date recorded in medical record |
| `status` | String | ACTIVE / INACTIVE |

## 4. Conditions (`conditions.csv`)

| Field Name | Type | Description |
|---|---|---|
| `patient_id` | String | Foreign key to Patients |
| `condition` | String | Comorbidity diagnosis string |
| `severity` | String | MILD / MODERATE / HIGH |
| `diagnosis_date` | String | Diagnosis record date |
| `status` | String | ACTIVE / INACTIVE |

## 5. Observations (`observations.csv`)

| Field Name | Type | Description |
|---|---|---|
| `patient_id` | String | Foreign key to Patients |
| `observation_date` | String | ISO Timestamp |
| `blood_pressure` | String | Systolic / Diastolic mmHg |
| `heart_rate` | Integer | Beats per minute |
| `temperature` | Float | Celsius |
| `oxygen_saturation` | Integer | Percentage (%) |
| `creatinine` | Float | Serum creatinine mg/dL |
| `glucose` | Integer | Blood glucose mg/dL |

## 6. Synthetic Interactions (`interactions.csv`)

| Field Name | Type | Description |
|---|---|---|
| `rule_id` | String | Rule identifier (R-ALL-001, R-MED-001, R-COM-001) |
| `rule_type` | String | Medication-Allergy, Medication-Medication, Medication-Comorbidity |
| `medication_a` | String | Primary drug agent |
| `medication_b` | String | Secondary drug agent |
| `related_allergen` | String | Related allergen group |
| `related_condition` | String | Related condition substring |
| `risk_level` | String | HIGH / MODERATE / REVIEW |
| `evidence_strength` | String | HIGH / MODERATE |
| `description` | String | Rule description (Labeled as Synthetic Demonstration Rule) |
